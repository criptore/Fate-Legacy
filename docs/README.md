# Fate Legacy: project docs

Notes for anyone reading or contributing to the code. The player-facing
overview is the [main README](../README.md).

- **[canon.md](canon.md)**: every design choice that claims to come from the
  novel, with its source and whether it has been verified, plus everything
  that is invented. Check it before writing content that touches Rank, Class,
  Aspect or Lineage.
- **[balance.md](balance.md)**: the two design rules, simulation results,
  and how to read them.
- **[development.md](development.md)**: running locally, file layout, the HUD,
  the event format, and the rules the validator enforces.
- **[content/](content/README.md)**: how content packs and modules work, and
  one page per pack or module describing what it adds.
